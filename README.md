# 밤공부 — 심야 자습 좌석 신청

기숙사 방 번호에서 층을 자동 추출하고, 해당 층의 1~7번 좌석을 매일 신청하는 작은 웹 서비스입니다.

## 실행

Node.js 18 이상만 있으면 별도 패키지 설치 없이 실행됩니다.

```bash
npm start
```

브라우저에서 `http://127.0.0.1:3000`을 여세요.

## 주요 규칙

- 방 번호는 `A303`, `B206` 형식이며 동 문자는 무시하고 숫자의 첫 자리를 층으로 사용합니다.
- 별도 아이디 없이 이름과 비밀번호로 로그인하며, 같은 이름은 중복 가입할 수 없습니다.
- 신청 시간은 매일 한국 시간 18:00~23:50입니다.
- 학생당 하루 한 좌석만 신청할 수 있습니다.
- 같은 층의 같은 좌석은 중복 신청할 수 없습니다.
- 신청 시간 안에는 자신의 신청을 취소하고 다시 선택할 수 있습니다.
- 계정과 신청 내역은 `data/db.json`에 저장되며, 비밀번호는 scrypt로 해시됩니다.

## 설정

환경 변수로 포트와 신청 시간을 바꿀 수 있습니다.

```powershell
$env:PORT=8080
$env:OPEN_HOUR=18
$env:CLOSE_HOUR=23
$env:CLOSE_MINUTE=50
npm start
```

## 운영 전 확인할 점

현재 버전은 학교 내부망이나 프로토타입용입니다. 실제 운영 시에는 HTTPS, PostgreSQL 같은 정식 DB, 관리자 화면, 학생 명단 기반 가입 승인, 로그인 시도 제한 및 백업을 추가하는 것이 좋습니다.
